# DizyTV 0.1.18-alpha release-candidate acceptance

**Status:** unreleased; the previously passing five-platform candidate was built
from `8eef3ae`. Later Ace recording/review fixes must pass new source and native
CI before they can be merged. Do not substitute the old binary for the new
branch head. Do not close #27/#28/#30/#32 solely because GitHub builds pass.

## Automated gates (GitHub Actions)

- [ ] Python source QA, including media/timeshift, Ace recording, alternate
  selection, settings and upgrade regressions, passes at the final commit.
- [ ] Five native jobs pass at **the same** commit: Windows x64 EXE, Intel Mac
  PKG, Apple Silicon Mac PKG, Ubuntu/Debian amd64 DEB and Android APK.
- [ ] Native executable tests actually load bundled VLC and FFmpeg, decode
  synthetic video AND audio, and import Vosk including libvosk.dyld on Mac.
- [ ] macOS PKGs contain matching CPU architecture and bundled Outpace under
  its upstream AGPL source/licence terms; Linux DEB uses distro libVLC.
- [ ] Licensing/source availability, video/FFmpeg module obligations, Apple
  ad-hoc signature limitations and Windows optional Ace Authenticode signer
  have been reviewed (a build passing does not validate publisher consent).

## Windows operator checks (#27, #30 and #32)

Use an authorised, unencrypted, known-good HTTP/HLS channel as the control.

- [ ] Install over an existing 0.1.17 installation. No access-denied/false
  "DizyTV is running" message from an idle recording worker. Existing
  playlists, EPG mapping, favourites, timers and recordings survive.
- [ ] First launch displays **all** top-bar button labels and logo, at
  Normal buttons and 80% interface scale, without needing to reapply
  Settings. Make the window shorter and narrower. The sidebar should scroll
  vertically without squashing category/filter labels.
- [ ] Clear HLS control plays **picture and sound inside DizyTV**, without
  system VLC, separate FFmpeg, or extra speech model installation.
- [ ] Test broadcast subtitles, CC **Off**, then CC On; where enabled,
  opt-in offline English Vosk starts and STOPS immediately. No ghost overlay,
  frozen UI or orphan recognition subprocess.
- [ ] Leave the control stream playing for at least **30 minutes**. While
  running, resize, pop out, open/close Guide, and switch channels repeatedly.
  Distinguish video stall from Windows "Not Responding".
- [ ] Test timeshift On/Off, short source/network stalls, pause, LIVE and
  channel-switch teardown. If a true hang occurs, enable **Tools → Log UI
  freezes locally**, reproduce and privately inspect the log. It may contain
  local account paths; never put provider tokens in a public GitHub comment.
- [ ] For ITV2 and E4, use **Tools → Selected channel source…** to identify
  the imported source label, and **Try another saved source…** if available.
  Record the exact user-facing diagnostic, not the confidential URL. An HTML
  landing page or DRM-restricted official player is *not* a direct TV stream.
- [ ] With the original optional Ace Engine task unchecked, clean setup
  must work without P2P. Any third-party opt-in must preserve its official
  installer UI/EULA, refuse an unexpected signer and keep DizyTV installed
  on failure. Do not run vendor installation tests without explicit consent.
- [ ] Schedule a recording and close the UI while it records. The detached
  worker must preserve the recording. Repeat with a future queued Ace timer;
  ensure helper selection is the configured original engine where supplied.

## Mac/Linux operator checks (#28)

- [ ] Intel and Apple Silicon: install the corresponding PKG on clean machines
  without VLC; test picture/audio, bundled English Vosk, FFmpeg, app startup,
  subtitle Off and close/reopen. Development builds are ad-hoc signed, not
  notarised; record actual macOS Gatekeeper behaviour.
- [ ] Test public, authorised compatible Ace swarm playback and recording
  using native Outpace. Confirm an existing original engine is honoured where
  explicitly configured. Verify no unrequested downloads or external bind.
  Stop playback/recordings and check for stray local Outpace daemons.
- [ ] Ubuntu 24.04: `sudo apt install ./DizyTV-*-linux-amd64.deb`
  resolves distro VLC/FFmpeg dependencies; test playback, captions and GUI
  on X11/XWayland. The proprietary original Ace Ubuntu 22.04 bootstrap is
  deliberately unsupported on 24.04; bundled open-source Outpace is distinct.

## Android

- [ ] Install the native APK and test channel browsing, player audio/video,
  favourites and guide on a real device. Desktop Vosk/FFmpeg functionality
  is **not** included in Android; never claim automatic caption parity.
