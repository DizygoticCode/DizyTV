DizyTV development candidate - Included Windows Components

The installer ALWAYS copies these components into DizyTV's private
application folder, regardless of whether Windows already has a separate
installation. You do NOT need to download or install these yourself:

  - Vosk 0.3.40 offline speech-recognition runtime (Apache 2.0)
  - Vosk Small English US 0.15 language model (Apache 2.0)
  - FFmpeg 8.1.2 essentials executable (GPL-licensed build)
  - VideoLAN VLC 3 private x64 playback DLLs and plugins (licence notices included)

These are used only when you opt into "Generate live subtitles"
from DizyTV's CC Subtitles menu. They do not run during installation.
FFmpeg is not added to the system PATH and does not modify existing
FFmpeg installations.

Still separate:
  - No separate VLC installation is required in the proposed self-contained Windows build.
  - Ace Stream engine for the optional Ace Stream channels

DizyTV cannot bypass broadcaster DRM or geographical access restrictions.
