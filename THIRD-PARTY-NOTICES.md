# Third-party components

DizyTV is an independent application. The Ace Stream engine is separately installed/configured; this project does not rename, redistribute or remove notices from Ace Stream binaries. No channel or XMLTV dataset is bundled.

- **Qt / PySide6 / Shiboken6 6.11.2** — Qt for Python, LGPLv3/GPLv3 or commercial terms, depending on the component. Desktop builds use dynamically linked libraries. Sources, licence terms and replacement/relinking information: <https://www.qt.io/licensing/open-source-lgpl-obligations>, <https://code.qt.io/cgit/pyside/pyside-setup.git/>. Copies of LGPLv3 and GPLv3 are included in `assets/licenses`; exact corresponding sources and replacement instructions remain a public release requirement.
- **python-vlc 3.0.21203** — LGPLv2.1 or later. <https://github.com/oaubert/python-vlc>. The native desktop package is being updated to include a private, original VideoLAN VLC 3.0.24 library and media modules. Official Windows x64 ZIP SHA-256: `fcf30850371ad10c9373cc4f0f4501e7dee49e3e9ae9f20c72fb2661a1ca6323`; universal macOS DMG for both Apple Silicon and Intel SHA-256: `2c8e89f7f42e53c2fb0e87b6dfa39b49f1364b25080aaa2e476ac74c0d7beb3c`. VideoLAN terms and separately licensed module/source and relinking obligations apply: <https://download.videolan.org/pub/videolan/vlc/3.0.24/>. **Do not ship a new public package until this compliance review is completed.**
- **Outpace 0.2.0 (proposed bundled macOS Intel/Apple Silicon and Linux amd64 engine)** — a separate Rust daemon under **AGPL-3.0-or-later**, independent of the proprietary Ace Stream engine. The Mac and Linux packages build the exact [upstream v0.2.0 source](https://github.com/jamezrin/outpace/tree/v0.2.0) at commit `e61be2aeb4e4ef3b4e6b42b22fe35f91271a7d5b` with Cargo.lock and includes the upstream full LICENSE alongside the executable. Corresponding source: <https://github.com/jamezrin/outpace/tree/e61be2aeb4e4ef3b4e6b42b22fe35f91271a7d5b>. Its HTTP API defaults to localhost in DizyTV, starts when the viewer chooses an Ace channel, and opts out of inbound seeding/automatic port mapping. This is an upstream-compatible public-swarm reimplementation, not a guarantee of proprietary engine parity or access to encrypted streams. Verify AGPL corresponding-source delivery requirements (and aggregation boundaries) before publicly shipping bundled builds.
- **libVLC Android 3.7.5** — VideoLAN's embedded library with its upstream LGPL and module-specific notices. <https://code.videolan.org/videolan/vlc-android>. The APK includes the licence texts and this notice. Exact corresponding sources and the LGPL replacement/relinking route remain a public release requirement. Do not assume the DizyTV source licence replaces upstream licences.
- **Python 3.12** — PSF licence. <https://docs.python.org/3/license.html>.
- **tzdata 2026.2** — IANA timezone database; Python tzdata package Apache 2.0. <https://github.com/python/tzdata>.
- **Vosk 0.3.40** — Apache 2.0 offline speech recognition runtime bundled into desktop packages. Speech recognition remains opt-in. <https://alphacephei.com/vosk/>.
- **Vosk Small English US model 0.15 (Windows, macOS and Linux desktop)** — Apache 2.0 offline acoustic/language model supplied with the native desktop installers (no first-run download). Original model and terms: <https://alphacephei.com/vosk/models>. The exact model archive is checksum-pinned to SHA-256 `30f26242c4eb449f948e42cb302dd7a686cb29a3423a8367f99ff41780942498`, obtained from the release mirror at <https://github.com/BartekReterski/VoskModels/releases/tag/v1>.
- **FFmpeg bundled native binary (macOS development work)** — `imageio-ffmpeg==0.6.0` native wheel includes FFmpeg executables for both macOS arm64 and x86_64; the original FFmpeg binary is copied unchanged into private app resources. The Python wrapper is BSD licensed, but the bundled FFmpeg binary has its **own separate LGPL/GPL and third-party-codecs obligations**, which must be inspected with `ffmpeg -L` and reviewed for corresponding source before publication. <https://pypi.org/project/imageio-ffmpeg/0.6.0/>.
- **FFmpeg 8.1.2 essentials static build (Windows)** — standalone, separately invoked GPL build by Gyan Doshi, redistributed unchanged as `_internal/speech/ffmpeg.exe` with DizyTV's Windows installer; it is not installed system-wide or added to PATH. Archive/terms: <https://github.com/GyanD/codexffmpeg/releases/tag/8.1.2>. Matching upstream FFmpeg source commit: <https://github.com/FFmpeg/FFmpeg/commit/38b88335f9>. Licensing and exact build configuration can be inspected with `ffmpeg.exe -L` and `ffmpeg.exe -version`. This binary may contain GPL-licensed codecs and external dependencies; GPL obligations and corresponding sources must be reviewed before stable redistribution. Archive SHA-256: `db580001caa24ac104c8cb856cd113a87b0a443f7bdf47d8c12b1d740584a2ec`.
- **requests 2.32.5** — Apache 2.0 HTTP helper used by Vosk. <https://github.com/psf/requests>.
- **cffi** — MIT-licensed C Foreign Function Interface runtime used by the Vosk binding; upstream licence included in the desktop bundle. <https://github.com/python-cffi/cffi>.
- **pycparser** — BSD-3-Clause Python C parser dependency of CFFI; upstream licence included with desktop packages. <https://github.com/eliben/pycparser>.
- **srt 3.5.3** — MIT subtitle/timecode parsing helper used by Vosk. <https://github.com/cdown/srt>.
- **tqdm 4.67.1** — MPL-2.0 AND MIT progress utility used by Vosk, including its file-specific upstream notices. <https://github.com/tqdm/tqdm>.
- **requests/tqdm transitive runtime wheels** — charset-normalizer, idna, urllib3, certifi, and where installed on Windows, colorama. Their copied upstream licence files are included in the desktop bundle under `assets/licenses/components`. <https://github.com/psf/requests>.
- **Pillow 12.3.0** — bundled Python imaging helpers (PIL Software License / HPND-style upstream terms); upstream licence copied into desktop packaging. <https://github.com/python-pillow/Pillow>.
- **PyInstaller 6.22.3** — GPL with its bootloader exception permitting bundled application distribution. <https://pyinstaller.org/en/stable/license.html>.

The desktop build copies upstream licence files from python-vlc, tzdata, Vosk, CFFI, pycparser, requests, srt, tqdm, requests' HTTP dependencies, Pillow and PyInstaller into `assets/licenses/components`, alongside the Python 3.12 licence and this notice. Where a Windows-specific dependency such as colorama is installed, its upstream notices are copied too. Android also bundles **AndroidX DocumentFile 1.0.1** (Apache 2.0), <https://android.googlesource.com/platform/frameworks/support/+/refs/tags/androidx-documentfile-release/documentfile/>. Licence copies are shipped as APK assets. Build-time Kotlin, Gradle, Android Gradle Plugin and JUnit are not application runtime libraries.

Desktop packages are unsigned development builds (macOS uses an ad-hoc app signature). A debug Android APK is a development artifact. Public release signing and the final redistribution/source-offer review (including bundled FFmpeg's corresponding source requirements) are separate release gates. No open-source licence for DizyTV itself has been selected by the owner yet; a public GitHub repository alone does not grant a source licence.
